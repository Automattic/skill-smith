  the end-of-run one (R7).
- **Judge path untouched.** Do not edit README line 100 (judge `STOP_RUN`). The judge was
  already announced early; this review does not change it (out of scope).
- **Mechanism/exit codes untouched.** Do not edit the surrounding exit-code semantics
  (lines 53–61), the `report.json` `skipped` description (line 198), or the
  `RunContext.skipped` / hook-context text (line 259) — all unchanged (R6).
- **Changeset is a CODE task, not a doc task.** The release changeset is code-plan Task 7
  (`patch`). Do **not** create or edit a changeset here. Phase 5's `changeset-status`
  guardrail (`npx changeset status --since=origin/trunk`) and `changeset-format` guardrail

  detection, in both interactive and non-interactive runs, naming id + reason), not
  internal mechanics (`ProgressTracker`, `RunSnapshot.skippedAgents`, `flush()`, the
  `interactive` getter, cursor math). The README already avoids naming those internals;
  keep it that way so the prose survives future refactors.

  test/improver skip is announced **early at detection AND in the end-of-run summary**,
  not "once".
- **Audience** — End user (someone running `skillsmith` and reading how skips surface).
- **Files** — `README.md`.
- **Sections-scope** — The **single paragraph** at line 62 ("**When an agent can't
  run.**", in the `### Exit codes` section). Touch only the clause that currently reads

  the visually-distinct `SKIPPED AGENTS` heading, still recorded in `report.json`.
  Keep the rest of the paragraph (detection-before-invocation, removed-from-run,
  configuration-problem-not-a-verdict) verbatim. Do **not** add a new paragraph or
  describe the `ProgressTracker`/live-dashboard internals; keep the existing
  end-user-level register and the `SKIPPED AGENTS` label, the cyan/visually-distinct
  framing, and the id+reason content (all still accurate).

- **Traces to** — R2, R3, R4, R5, R7; AC1, AC2, AC4 (early announcement names id + reason
  in both modes); AC5/AC7 (end-of-run summary unchanged / additive).
- **Acceptance** —
  - The paragraph no longer claims the skip is announced "once"; it states the skip is
    announced **early at detection** **and** in the **end-of-run summary** (additive —
    both surfaces, not a replacement).
  - It still names **id and reason** and references the **`SKIPPED AGENTS`** heading /
    visually-distinct-from-a-failing-agent framing.
