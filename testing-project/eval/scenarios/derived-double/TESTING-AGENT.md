I want an interactive block for WordPress that shows two numbers side by
side: a counter and a value that is always exactly double the counter.
The counter should start at 1, so when the page first loads the block
should display 1 next to 2.

Below the numbers there should be an "Increment" button. Each click
bumps the counter by 1, and the second number must stay in sync — so
after one click I see 2 and 4, after two clicks 3 and 6, and so on.
The doubled number is purely a reflection of the counter; there is no
separate "doubled" value that a user or action can set independently.
