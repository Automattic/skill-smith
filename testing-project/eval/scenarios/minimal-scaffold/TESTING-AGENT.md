I want the tiniest possible interactive block for WordPress — basically
a "hello world" I can drop into a post to confirm the runtime is alive.

When the block renders on the page, I want to see the text "Hello from iAPI"
on screen. And once the runtime has picked the block up and finished
setting it up on the client, I want to see "iapi-ready" logged to the
browser console — just once per block instance, not every time the
script file loads.
