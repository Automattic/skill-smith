I want an interactive block for WordPress for an expandable note.
It should render a button with a short paragraph beneath it. When
the page first loads, the paragraph is hidden and the button reports
aria-expanded="false". Clicking the button reveals the paragraph and
flips aria-expanded to "true"; clicking it again hides the paragraph
and flips aria-expanded back to "false". The button's aria-expanded
value should always match whether the paragraph is currently visible.
